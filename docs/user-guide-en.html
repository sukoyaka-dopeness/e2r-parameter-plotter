E2R application guide

Compare Entities with Dimensions

ParameterPlotter helps you record and compare numeric Assessments for the Entities in an E2R Dataset. You can use the same Dataset in other E2R applications while each application gives you a different view.

An Assessment is an authored value in the Dataset. ParameterPlotter does not infer a value from an Entity name or its relationships. A recorded 0 is different from no Assessment.

Start with a Dataset

On Home, choose Open Sample Dataset · The Ashen Crown to explore the built-in example. The sample language follows the ParameterPlotter UI language. Choose Open E2R Dataset to select a JSON file, or New Dataset to start fresh.

If your browser already has saved work, replacing it may show a confirmation. Choose Cancel to keep the current workspace. A configured Hub link can open a Dataset at startup; a failed fetch or invalid response leaves the current Dataset unchanged.

Set up comparison Dimensions

A Dimension defines what you want to compare, its numeric MIN and MAX, and optional endpoint labels. In the Workspace, use the Dimensions action to create or edit a Dimension. You can also set an optional unit and choose whether values must be integers. Keep each Dimension's scale meaningful for the question you are asking.

New Datasets receive a Dimension Assessment payload when you save their first Dimension. A Dimension Description is optional plain text; line breaks are preserved. On a Candidate 0.1.0 Dataset, explicitly choose the offered upgrade before adding a Description. The upgrade preserves existing IDs and values and does not create descriptions for you.

If a change would make recorded values invalid, ParameterPlotter asks you to review a rescale before applying it. Existing values are not silently rounded or removed.

Record and compare Assessments

Choose an Entity and enter an Assessment for a Dimension. Profile and Matrix provide direct numeric inputs; Profile can also use the range control when the value can be safely set. Clear a value explicitly to return it to the unassessed state. Leave a cell empty when no value is appropriate or available.

  • Profile shows one Entity's values across Dimensions.
  • Radar compares the selected primary Entity across chosen Dimensions. A secondary Entity is a visual comparison. Focus a plotted primary value and use the arrow keys to adjust it; each step follows that Dimension's range and integer rule.
  • Quadrant compares Entities on selected X and Y Dimensions. Drag a point or focus it and use the arrow keys: Left/Right adjust X; Up/Down adjust Y. Enter or Space selects the Entity. Selection does not change its values.
  • Matrix displays Entity-by-Dimension values. Edit a cell directly, reorder rows or columns where controls are shown, and use the page arrows to cycle through Dimensions.

View navigation and editing controls also support keyboard focus. The UI language can change independently of Dataset-authored names, labels, and descriptions.

Keep and share your work

ParameterPlotter saves the working copy in this browser when local storage is available. This browser-local copy is useful for continuing on the same browser, but it is not an exported Dataset file. Use More → Export E2R JSON to download a portable copy and keep that file somewhere you control.

The workspace indicates whether changes have been exported and whether browser-local saving is available. If saving to browser storage fails, the in-memory work may be lost when you reload or close the browser. Export a file for a portable copy.

Use More → Open E2R Dataset to open another local file. A Hub startup link can retrieve a Dataset from its configured source. ParameterPlotter does not host or publish that source. Replacing loss-sensitive work requires explicit confirmation; Cancel keeps the active workspace.

Examples and compatibility

The built-in Ashen Crown example includes seven Dimensions and 70 Assessments. The Hub also presents Lighthouse Restoration Project and Cedar Observatory examples when their owner sources and ParameterPlotter handoff are configured. These examples include unassessed cells; they are not treated as zero.

Dimension Assessment is currently a non-Stable Candidate extension. Another application may preserve extension data without displaying or editing it. Keep an exported E2R JSON copy when moving important work between tools.
