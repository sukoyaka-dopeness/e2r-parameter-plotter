# 評価軸でエンティティを比較する

*ParameterPlotter ユーザーガイド · 日本語*

ParameterPlotterでは、E2Rデータセットに含まれるエンティティの数値評価を記録し、比較できます。同じデータセットをほかのE2Rアプリケーションで利用すると、異なる視点から内容を扱えます。

> Assessment（評価値）はデータセットに記録する値です。ParameterPlotterがエンティティ名やつながりから評価を推測することはありません。明示的な **0** と、評価が未記録であることは別の状態です。

## データセットを開く

ホームで「サンプルデータセットを開く · 灰冠の王国」を選ぶと、内蔵サンプルを試せます。サンプルの言語はParameterPlotterのUI言語に対応します。「E2Rデータセットを開く」ではJSONファイルを選択でき、「新しいデータセット」では空の状態から始められます。

ブラウザーに作業中のデータがある場合、置き換え前に確認が表示されることがあります。「キャンセル」を選ぶと現在の作業を保持します。Hubに設定された起動リンクからデータセットを取得できますが、取得や応答の検証に失敗した場合、現在のデータセットは置き換わりません。

## 評価軸を用意する

Dimension（評価軸）は、何を比較するか、数値のMIN/MAX、任意の端点ラベルを定義します。Workspaceの評価軸操作から作成・編集できます。任意で単位や、整数のみを許可する設定も指定できます。評価したい問いに合う尺度を選んでください。

新しいデータセットでは、最初の評価軸を保存するとDimension Assessment payloadが作成されます。評価軸のDescription（説明）は任意のプレーンテキストで、改行も保持されます。Candidate 0.1.0のデータセットで説明を使うには、表示されるUpgradeを明示的に選びます。IDや既存値は維持され、説明文が自動生成されることはありません。

変更後に記録済みの値が無効になる場合、適用前に再計算結果を確認します。既存値が暗黙に丸められたり削除されたりすることはありません。

## 評価値を記録して比較する

エンティティを選び、評価軸ごとに値を入力します。ProfileとMatrixでは数値入力欄を使えます。安全に設定できる場合はProfileの範囲コントロールも利用できます。値を消去すると未評価に戻ります。適切な値がない、または分からない場合は、0で埋めず未評価のままにします。

- **Profile**では、1つのエンティティについて複数の評価軸の値を確認・編集します。
- **Radar**では、主エンティティの複数評価軸を比較します。比較エンティティは表示上の参照です。主エンティティの値にフォーカスし、矢印キーで調整できます。刻みと範囲は評価軸の設定に従います。
- **Quadrant**では、選択したX/Y評価軸でエンティティを比較します。点をドラッグするか、点にフォーカスして矢印キーを使います。左右キーはX、上下キーはYを調整します。EnterまたはSpaceでエンティティを選択します。選択だけでは値は変わりません。
- **Matrix**では、エンティティと評価軸の値を表形式で確認できます。セルを直接編集し、表示された操作で行・列を並べ替えたり、評価軸のページを移動したりできます。

画面移動や編集操作はキーボードでも利用できます。UIの言語を切り替えても、データセットに書かれた名前、端点ラベル、説明は翻訳・変更されません。

## 作業を保存・共有する

利用できる場合、ParameterPlotterは作業状態を現在のブラウザー内に保存します。これは同じブラウザーで作業を続けるための保存で、持ち運べるデータセットファイルとは別です。「その他」→「E2R JSONを書き出す」を選び、ダウンロードしたファイルを保管してください。

画面には、前回の書き出しから変更があるか、ブラウザー内に保存できているかが表示されます。ブラウザー内の保存に失敗した場合、再読み込みやブラウザーを閉じた後に、メモリー上の作業を失う可能性があります。持ち運べるコピーにはE2R JSONを書き出してください。

「その他」→「E2Rデータセットを開く」ではローカルファイルを開けます。Hubに設定された起動リンクからもデータセットを取得できます。ParameterPlotterが取得元をホスト・公開するわけではありません。置き換えで作業を失う可能性がある場合は、明示的な確認が表示されます。「キャンセル」で現在の作業を維持できます。

## サンプルと互換性

内蔵の灰冠の王国サンプルには7つの評価軸と70件の評価値があります。Hubでは取得元とParameterPlotterへの導線が設定されている場合、Lighthouse Restoration ProjectとCedar Observatoryのサンプルも利用できます。未評価のセルは0として扱われません。

Dimension Assessmentは現在non-StableのCandidate拡張です。ほかのアプリケーションが拡張データを保持しても、表示・編集に対応していない場合があります。重要な作業を別のツールへ移すときは、E2R JSONを書き出して保管してください。
