# 評価軸でエンティティを比較する

*ParameterPlotter ユーザーガイド · 日本語*

ParameterPlotterでは、E2Rデータセットに含まれるエンティティの数値評価を記録し、4種類の画面で比較できます。まず内蔵サンプルを試すか、手元のデータセットを開いてください。アプリケーション版は **0.1.0** です。

## データセットを開く

ホームで「灰冠の王国の例を開く」を選ぶと、10件のエンティティ、7つの評価軸、70件の評価値を含む内蔵サンプルを試せます。UI言語に合わせて英語版または日本語版のデータセットが開きます。ボタンの下にある「サンプル情報」から、出典と権利に関する情報を確認できます。「E2R Datasetを開く」ではJSONファイルを選択でき、「新しいDataset」では空の状態から始められます。

ホームには現在のUI言語に対応するガイドのリンクだけが表示されます。日本語UIでは「日本語ユーザーガイド」、英語UIでは「English user guide」です。ホームから英語版を開くにはUI言語を切り替えてください。このガイドの末尾からも英語版へ移動できます。Dataset操作とガイドの下には、任意の支援先として「GitHub SponsorsでE2Rを支援する」と「Ko-fiでE2Rを支援する」があります。保存済みのブラウザー内Workspaceを再開できるときは「編集を続ける」が表示されます。現在のWorkspaceに戻れるもののブラウザー内保存が低下しているときは、代わりに「Workspaceに戻る」が表示されます。

ブラウザーに作業中のデータがある場合、データセットと比較用Workspaceの置き換え前に確認が表示されることがあります。「キャンセル」を選ぶと現在の作業を保持します。残したい変更は置き換え前に書き出してください。Hubに設定された起動リンクからもデータセットを取得できますが、取得や応答の検証に失敗した場合、現在のデータセットは置き換わりません。

## 評価軸を用意する

Dimension（評価軸）は、何を比較するか、数値のMIN/MAX、任意の端点ラベルを定義します。Workspaceの評価軸操作から作成・編集できます。任意で単位や、整数のみを許可する設定も指定できます。評価したい問いに合う尺度を選んでください。

評価軸のDescription（説明）は任意のプレーンテキストで、改行も保持されます。追加前にデータセットのUpgradeを求められたら、内容を確認して明示的に選んでください。

変更後に記録済みの値が無効になる場合、適用前に再計算結果を確認します。既存値が暗黙に丸められたり削除されたりすることはありません。

## 評価値を記録して比較する

エンティティを選び、評価軸ごとに値を入力します。ProfileとMatrixでは数値入力欄を使えます。安全に設定できる場合はProfileの範囲コントロールも利用できます。値を消去すると未評価に戻ります。明示的な **0** と、評価が未記録であることは別の状態です。適切な値がない、または分からない場合は、0で埋めず未評価のままにします。ParameterPlotterは名前やつながりから値を推測しません。

- **Profile**では、1つのエンティティについて複数の評価軸の値を確認・編集します。
- **Radar**では、主エンティティの複数評価軸を比較します。比較エンティティは表示上の参照です。主エンティティの値にフォーカスし、矢印キーで調整できます。刻みと範囲は評価軸の設定に従います。
- **Quadrant**では、選択したX/Y評価軸でエンティティを比較します。点をドラッグするか、点にフォーカスして矢印キーを使います。左右キーはX、上下キーはYを調整します。EnterまたはSpaceでエンティティを選択します。選択だけでは値は変わりません。
- **Matrix**では、エンティティと評価軸の値を表形式で確認できます。セルを直接編集し、表示された操作で行・列を並べ替えたり、評価軸のページを移動したりできます。

画面移動や編集操作はキーボードでも利用できます。UIの言語を切り替えても、データセットに書かれた名前、端点ラベル、説明は翻訳・変更されません。

## 作業を保存・共有する

利用できる場合、ParameterPlotterは作業状態を現在のブラウザー内に保存します。これは同じブラウザーで作業を続けるためのWorkspaceで、**持ち運べるデータセットファイルではありません**。「その他」→「E2R JSONを書き出す」でダウンロードを依頼し、ファイルが保存されたことを確認してください。別のブラウザーやアプリへ持ち出したい変更を加えたら、再度書き出します。

画面には、前回の書き出しから変更があるか、ブラウザー内に保存できているかが表示されます。保存容量の不足、ブラウザーの設定や管理者による保存制限、一時的な保存エラーなどで、ブラウザー内への保存が失敗することがあります。ParameterPlotterが正確な原因を特定できるとは限りません。現在の作業が保存されなかった場合、再読み込みやブラウザーを閉じた後に、メモリー上の作業を失う可能性があります。重要な作業はE2R JSONを書き出して保管してください。

「その他」→「E2R Datasetを開く」ではローカルファイルを開けます。Hubに設定された起動リンクからもデータセットを取得できます。ParameterPlotterが取得元をホスト・公開するわけではありません。置き換えで作業を失う可能性がある場合は、明示的な確認が表示されます。「キャンセル」で現在の作業を維持できます。

## サンプルと互換性

Hubでは取得元とParameterPlotterへの導線が設定されている場合、Lighthouse Restoration ProjectとCedar Observatoryのサンプルも利用できます。未評価のセルは0として扱われません。

Dimension Assessmentは現在non-StableのCandidate拡張です。ほかのアプリケーションが拡張データを保持しても、表示・編集に対応していない場合があります。重要な作業を別のツールへ移すときは、E2R JSONを書き出して保管してください。

## 作業状態と高度な操作

同じOrigin・同じブラウザープロファイルで編集できるParameterPlotterのタブは1つです。最初のタブはHomeにいる間もセッションを保持します。別のタブには元のタブへ戻るよう案内が表示され、データセットの取得や編集はできません。元のタブを閉じても別のタブは自動的には使えるようになりません。再読み込みするか開き直して、最後に正常保存されたWorkspaceを再開してください。別のページへ移動して戻った場合も、終了したセッションの再開には再読み込みが必要です。クラッシュ直前の未適用入力の復旧は保証されません。

新しいデータセットでは、最初の評価軸を保存するとDimension Assessmentのデータが作成されます。Candidate 0.1.0のデータセットで説明を追加するには、表示されるUpgradeを明示的に選びます。IDや既存値は維持され、説明は自動生成されません。Dimension Assessment `0.2.0` は引き続きStableではない仕様Candidateです。
